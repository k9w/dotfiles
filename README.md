# _My Configuration Files, Dotfiles, etc._

## Description

This repository conatains the system and user-sepcific configuration
files I use, on OpenBSD, FreeBSD, Linux, and perhaps soon NetBSD and
DragonflyBSD, as well as any that are common to multiple or all of them.
